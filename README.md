# matan — консольные решатели уравнений

Консольные приложения на Python (вычисления — [SymPy](https://www.sympy.org)).

```bash
pip install -r requirements.txt
```

## 0. Калькулятор с ходом решения — `calculator.py`

Полностью на русском: команды, пояснения к каждому шагу и сообщения об ошибках.

```bash
python calculator.py                         # интерактивный режим, «помощь» — справка
python calculator.py "производная x^2 sin(x)" "x^2 - 5x + 6 = 0"
```

| Что | Пример ввода | Что показывает |
|---|---|---|
| Вычисления | `7/3`, `√8`, `sin(pi/6)`, `10!`, `0,1 + 0,2` | точный ответ и приближение |
| Производная | `производная x^2 sin(x)`, `(x^3)''`, `производная x^2 y по y порядка 2` | правило на каждом шаге: сумма, произведение, частное, сложная функция, таблица |
| Интеграл | `интеграл x e^x dx`, `интеграл sin(x) от 0 до pi` | замена, по частям, табличные интегралы, Ньютон–Лейбниц, несобственные интегралы, проверка |
| Предел | `предел sin(x)/x при x -> 0`, `предел (1+1/x)^x при x -> ∞`, `x -> 0+` | подстановка, тип неопределённости, сокращение, деление на старшую степень, Лопиталь, 1^∞ |
| Уравнения | `x^2 - 5x + 6 = 0`, `sin(x) = 1/2`, `(x+1)/(x-1) = 2`, `cos(x) = x` | дискриминант, разложение на множители, ОДЗ, тригонометрические формулы, численное решение |
| Системы | `x + y = 5; x y = 6`, `2x + y = 5; x - y = 1` | метод подстановки или метод Гаусса |
| Неравенства | `(x - 1)/(x + 2) >= 0`, `x^2 ≤ 9` | метод интервалов со знаками |
| Ряд Тейлора | `ряд e^x`, `ряд ln(x) в точке 1 до 4` | таблица производных и коэффициентов |
| Матрицы | `определитель 1 2 3; 4 5 6; 7 8 10`, `обратная 2 1; 1 1` | разложение по строке, присоединённая матрица |
| Преобразования | `упростить …`, `раскрыть …`, `разложить x^2 - 1`, `разложить 360`, `дроби …` | |
| Переменные | `пусть a = 5`, `пусть f(x) = x^2 + 1`, `f(a)`, `ans` | |
| Другие решатели | `ду y' = x y, y(0) = 2`, `линейные` | |

Ошибки ввода объясняются по-русски с указанием места:

```
>>> 2*(x+1
Ошибка ввода: не закрыта скобка «(»
    2*(x+1
      ^
>>> sinx + 1
Ошибка ввода: «sinx»: аргумент функции пишется в скобках — sin(x) или sin x
>>> производна x^2
```

Также распознаются: русские буквы вместо латинских (`2х + 1`), `×`, `÷`, `−`, `²`,
`√`, `π`, `∞`, `|x|`, `≤`, `≥`, деление на ноль, пустые скобки, два знака подряд,
лишние запятые, неизвестные функции (с подсказкой).

## 1. Линейные уравнения и системы — `linear_solver.py`

Решает одно линейное уравнение или систему методом Гаусса: показывает расширенную
матрицу, ступенчатый вид, ранги (теорема Кронекера–Капелли) и ответ — единственное
решение, общее решение со свободными неизвестными или «решений нет».

```bash
python linear_solver.py                         # интерактивно: уравнения по одному в строке
python linear_solver.py "3x - 7 = 2"
python linear_solver.py "2x + y = 5" "x - y = 1"
python linear_solver.py "x1 + x2 + x3 = 1" "2x1 - x2 = 0.5"
```

## 2. Дифференциальные уравнения первого порядка — `ode_solver.py`

Меню из двух пунктов:

1. **Уравнения с разделяющимися переменными** `y' = X(x)·Y(y)` — разделение
   переменных, интегралы обеих частей, общий интеграл, явный ответ и решения,
   потерянные при делении на `Y(y)`.
2. **ДУ первого порядка** — тип определяется автоматически, решение с шагами:
   * с разделяющимися переменными;
   * линейное `y' + P(x)y = Q(x)` (интегрирующий множитель);
   * Бернулли `y' + P(x)y = Q(x)yⁿ` (замена `z = y^(1-n)`);
   * однородное `y' = φ(y/x)` (замена `y = ux`);
   * в полных дифференциалах `M dx + N dy = 0`;
   * остальные — через `sympy.dsolve`.

Можно задать начальное условие (задача Коши) `y(x0) = y0`. Каждое явное решение
проверяется подстановкой в уравнение.

```bash
python ode_solver.py                                         # интерактивное меню
python ode_solver.py "y' = x*y" --ic "y(0) = 2"
python ode_solver.py --separable "dy/dx = (1 + y^2)/(1 + x^2)"
python ode_solver.py "y' + y/x = x^2" --ic "y(1) = 1"
python ode_solver.py "y' + y = x y^3"
python ode_solver.py "y' = (x^2 + y^2)/(x y)"
python ode_solver.py "(2xy + 1)dx + (x^2 + 2y)dy = 0"
```

### Синтаксис ввода

* производная: `y'` или `dy/dx`; дифференциальная форма: `... dx + ... dy = 0`;
* знак умножения можно опускать: `2xy`, `3sin(x)`, `x y'`;
* степень: `^` или `**`; `e^x`, `exp(x)`, `ln`, `sqrt`, `sin`, `tg`, `arctg` и т. д.;
* дробная часть — точкой или запятой: `0.5`, `0,5`.

Код с ходом решения лежит в пакете `calc/`, разбор и проверка ввода — в `common.py`.
